# Galeria personale\n\nNgarkoni këtu fotografitë që dëshironi të shfaqen në galerinë publike të faqes.\n\nFormate të mbështetura: JPG, JPEG, PNG, WEBP dhe GIF.\n\nPër publikim: hapni dosjen `galeria`, zgjidhni **Add file → Upload files**, ngarkoni fotografinë dhe përfundoni me **Commit changes**. Faqja i lexon automatikisht skedarët e imazheve nga kjo dosje. Për të hequr një fotografi, fshini skedarin përkatës nga repository.\n
